# 顶部用量文字样式匹配设计

- 日期：2026-08-14
- 状态：用户已确认设计，待实现
- 范围：仅调整顶部用量展示的字体大小与颜色

## 目标

让“用量：每周 …”及其缩略文案的字体大小、字体族、字重、行高和颜色跟随 Codex 顶部菜单按钮（包括“帮助”）的当前计算样式。保留现有文案、完整/缩略切换、用量监听、刷新逻辑、挂载位置和生命周期行为。

## 方案

在 `src/inject.js` 创建用量根节点时，不再给根节点设置固定的 `font` 或 `color`。改为让根节点及完整、缩略、测量节点使用 `inherit`，从其顶部菜单承载容器继承实际字体和颜色。根节点继续保留现有的非交互、单行、拖拽区域和布局约束；不新增 CSS 文件，不读取版本号，也不依赖具体文案、类名或固定字号。

完整文案、缩略文案和隐藏测量文案共享同一继承样式，因此测量宽度与实际完整文案一致，不改变模式选择边界。主题切换、Codex 版本样式变化或系统字体变化由浏览器现有样式继承机制处理。

## 验证

1. 在注入契约测试中断言源代码不再设置固定 `font:` 和 `color: var(--text-primary, currentColor)`，并包含 `font: inherit`、`color: inherit` 的样式继承声明。
2. 运行注入契约测试，确认现有挂载、缩略选择和安全约束不变。
3. 运行全量 Node 测试，确认无其他行为回归。
4. 同步 `src/inject.js` 到当前用户安装副本并比较 SHA-256；不重启 Codex，真实界面生效留待用户下次按既有入口启动。

## 非目标

- 不改变显示文案、百分比计算、官方刷新/监听逻辑或 API。
- 不修改 Codex 官方 AppX、`app.asar` 或官方菜单节点。
- 不新增按钮、交互、独立定时器或网络请求。
